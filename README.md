Что делает скрипт ds_arch-installer.sh

    Проверка интернета - убеждается, что есть подключение

    Выбор диска - показывает все доступные диски

    Разметка - 3 варианта на выбор:

        Простая (EFI + корневой)

        С отдельным /home

        Ручная через cfdisk

    Форматирование - автоматически форматирует разделы

    Монтирование - монтирует разделы в /mnt

    Выбор пакетов:

        Xorg

        Видеодрайверы (Intel, NVIDIA, AMD, VirtualBox)

        Шрифты

        Дисплейный менеджер (SDDM, GDM, LightDM, LXDM)

        Окружение рабочего стола (GNOME, KDE, Cinnamon, XFCE, i3 и др.)

        Звуковая система

        Дополнительные пакеты

    Установка - устанавливает все выбранные пакеты

    Настройка:

        Часовой пояс

        Локали

        Имя хоста

        Пароль root

        Создание пользователя

        Настройка sudo

    Установка загрузчика - GRUB и настройка

    Включение служб - NetworkManager и дисплейный менеджер

Требования

    Загрузка с Arch Linux ISO

    Подключение к интернету

    Минимум 4GB RAM (рекомендуется)
